Latest proprietary NVIDIA drivers pre-installed. No terminal commands, no blacklisting nouveau—just boot and play.

Hybrid Graphics

Hybrid laptops with Intel/AMD + NVIDIA just work. Switch between integrated and discrete graphics effortlessly in the control center.

Full support for ASUS gaming laptops with asusctl and ROG Control Center. Control RGB lighting, fan profiles, and performance modes out of the box.
